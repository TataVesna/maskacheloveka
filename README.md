# Маска человека

**«Маска человека»** — браузерная мини-игра в формате auto-runner по мотивам проекта «Песни земли». Игрок управляет Кудым-Ошем, который автоматически движется к Костэ и по пути переключается между обликом человека и медведя, чтобы проходить разные типы препятствий.

## Как играть

Маршрут проходит через последовательность локаций: **берлога → тайга → курган / пещера → река → городище → чум невесты**. В середине маршрута находится встреча с ведьмой и чекпоинт. После завершения основной дистанции доступен бесконечный режим с процедурной генерацией групп локаций и препятствий.

### Управление

**Компьютер**
- ЛКМ — прыжок.
- ПКМ — смена облика.

**Телефон / планшет**
- свайп вверх — прыжок;
- тап — смена облика;
- игра рассчитана на горизонтальную ориентацию устройства.

## Основные правила

- Некоторые препятствия доступны только человеку или только медведю.
- Овраги и цветные кусты требуют прыжка в подходящем облике.
- Через глубокую воду медведь проходит вброд.
- Хрупкий мост и толпа рассчитаны на человека.
- В пещере находятся отдельные препятствия: низкий проход, стена и высокий проход.
- После встречи с ведьмой активируется чекпоинт.
- Основной маршрут соответствует дистанции 300 м.
- В бесконечном режиме дистанция не ограничена.

## Технологии

Проект сделан без фреймворков и сборщиков: **HTML + CSS + vanilla JavaScript**. Все игровые изображения хранятся локально, преимущественно в формате PNG. Игра не требует установки зависимостей.

## Структура проекта

```text
maska-cheloveka/
├── index.html                  # разметка игры и порядок подключения модулей
├── style.css                  # основные стили игрового мира и интерфейса
├── fonts.css                  # подключение шрифта
├── tutorial-overrides.css     # финальные настройки положения туториала
├── game.js                    # ядро: цикл игры, управление, базовые препятствия
├── route-layout.js            # размещение препятствий на основном маршруте
├── cave-layout.js             # логика и графика препятствий пещеры
├── form-bush-obstacles.js     # цветные кусты и правила нужного облика
├── river-jump.js              # уточнения поведения у воды
├── jump-visual.js             # параметры и визуальное поведение прыжка
├── checkpoint.js              # респаун после ведьмы
├── witch-scene.js             # встреча с ведьмой
├── adaptive-scale.js          # адаптивное масштабирование персонажей и объектов
├── speed-progression.js       # изменение скорости по мере прохождения
├── final-scene.js             # финальная сцена основной дистанции
├── result-screen.js           # экран результата и переходы после забега
├── tutorial-flow.js           # показ и скрытие обучения
├── endless-mode.js            # процедурный бесконечный режим
└── assets/
    ├── characters/            # персонажи и кадры анимаций
    ├── locations/             # фоны локаций
    ├── obstacles/             # препятствия
    └── UI/                    # элементы интерфейса
```

### Важно о JavaScript

`game.js` создаёт базовое состояние игры. Остальные JS-файлы подключаются после него и дополняют или уточняют отдельные механики. Поэтому **порядок `<script>` в `index.html` имеет значение**.

## Запуск на компьютере

Самый стабильный вариант — открыть папку `maska-cheloveka` в VS Code и запустить `index.html` через **Live Server**. Для быстрой проверки на компьютере проект также может открываться напрямую из `index.html`, однако локальный HTTP-сервер лучше воспроизводит условия публикации.

## Проверка на телефоне

Для локальной проверки компьютер и телефон можно подключить к одной Wi‑Fi сети и открыть адрес Live Server через локальный IPv4-адрес компьютера, например:

```text
http://192.168.1.20:5500/maska-cheloveka/index.html
```

Для проверки без общей сети проект публикуется через **GitHub Pages**. В репозитории уже находится workflow `.github/workflows/pages.yml`, который публикует содержимое `maska-cheloveka/` после изменений в ветке `main`.

Ожидаемый адрес GitHub Pages:

```text
https://tatavesna.github.io/maskacheloveka/
```

Если Pages ещё не активирован для репозитория, в GitHub нужно открыть **Settings → Pages → Build and deployment → Source → GitHub Actions**.

## Финальный архив

Workflow `.github/workflows/package.yml` собирает сдаваемый ZIP автоматически. В архив входят:

- этот `README.md`;
- рабочая папка `maska-cheloveka/` со всем кодом;
- PNG-визуалы и остальные необходимые ассеты.

Архив не требует `node_modules`, установщика или дополнительной сборки.
